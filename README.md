# The Invisible Resume Editor

The Invisible Resume Editor is a specialized web application designed for senior developers to optimize their professional resumes for specific job descriptions. This tool utilizes artificial intelligence to perform precise content adjustments while maintaining the structural integrity of Microsoft Word documents.

## Core Capabilities

### Document Processing
The application performs client-side manipulation of .docx files using PizZip and custom XML parsing. It addresses the challenge of fragmented text nodes in Word documents by normalizing paragraph structures before performing content replacements. This ensures that formatting, fonts, and layout remain consistent with the original document.

### AI Integration
Content optimization is powered by the Gemini 1.5 Flash model. The system analyzes the original resume text alongside a provided job description to identify and rewrite professional summaries, technical skill sets, and experience bullet points. The rewrite process emphasizes alignment with the target role while preserving the user's actual professional history and expertise.

### Security and Privacy
The application operates entirely within the user's browser. It requires a Google AI Studio API key, which is stored in the local storage of the browser and is never transmitted to any external server except for the official Google API endpoint. No document data is stored or processed on a backend server.

## Technical Stack

* UI Framework: Tailwind CSS via Content Delivery Network
* Text Extraction: Mammoth.js
* Document Manipulation: PizZip and DOMParser
* AI Engine: Google Generative AI SDK
* File Export: FileSaver.js

## Implementation Instructions

1. Obtain a Gemini API key from the Google AI Studio platform.
2. Open the index.html file in a modern web browser.
3. Input the API key in the configuration section.
4. Upload a resume in .docx format.
5. Provide the target job description in the text area.
6. Click the optimization button to generate and download the revised document.
