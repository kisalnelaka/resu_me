# The Invisible Resume Editor

The Invisible Resume Editor is a specialized career tool that allows users to optimize their resumes and generate tailored cover letters for specific job roles. The application adapts your professional content to match job requirements while ensuring your original document formatting remains intact.

## Quick Start Guide

1. Obtain a Gemini API key from the Google AI Studio website.
2. Enter your API key in the configuration section of the application.
3. Upload your resume in .docx format by dragging it into the designated upload area.
4. Paste the job description or target role details into the text field.
5. Click the optimization button to process your documents.
6. Download your optimized CV and custom Cover Letter using the dedicated buttons.
7. Open the files in Microsoft Word or Google Docs to perform a final proofread and verification.

## Core Features

### Intelligent CV Optimization
The system analyzes your existing resume alongside the job description to identify key technical skills and experiences. It rewrites summaries and bullet points to maximize relevance while preserving your professional history and formatting.

### Custom Cover Letter Generation
The tool drafts a professional cover letter tailored to the specific position and company. This document is generated as a new Word file, providing a solid foundation for your application.

### Professional Naming Conventions
Output files are automatically renamed using a standard professional format. Resumes are saved as Name-Position.docx, and cover letters are saved as Name-Company-Position.docx.

### Private and Secure
The application operates entirely within your web browser. No resume data or API keys are sent to any external server except for the official Google API endpoint. Your sensitive professional information remains private.

## Technical Details

This project is built using Tailwind CSS for a modern interface and specialized libraries including Mammoth.js and PizZip. It uses a custom, library-free document generation engine to ensure maximum reliability and performance. It is a client-side application fully compatible with GitHub Pages.

## Important Note

This tool is designed to assist in the professional application process. As the final step, you must open the generated documents in a word processor to verify all content and formatting before submission.
